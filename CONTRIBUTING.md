# Contributing to SkillBridge – AI Internship Application Agent

We welcome contributions to SkillBridge! Please follow these guidelines:

## Code Conventions
- Frontend: React 18 functional components with hooks, Tailwind CSS, Lucide icons.
- Backend: FastAPI, SQLAlchemy ORM, Pydantic v2 schemas.
- Database: Neon PostgreSQL & Docker PostgreSQL compatibility.

## Pull Request Checklist
1. Fork and create feature branch.
2. Run frontend build `npm run build`.
3. Submit PR with detailed description.
